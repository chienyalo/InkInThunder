# 墨走風雷 / Ink in Thunder

2026 · 生成式草書筆勢研究 · Alicia Lo × Codex

## 創作

以張旭狂草的縱逸與連綿行氣為靈感，將轉折、提按、牽絲與飛白轉化成程式規則。每卷保留相同文字，但種子會改變字群大小、重心、傾斜、連筆與枯潤節奏。

文字由右至左，分為五行：

> 風起雲湧 / 山河入夢 / 墨走風雷 / 萬象生意 / 水月清心

這是本作的當代文字組合。

字形骨架使用 **Liu Jian Mao Cao** 草書字體，並非張旭墨跡的數位描摹。作品以張旭為筆勢與章法的靈感來源，畫面則是現代字形、演算法與種子變化的創作協作。字體中風、雲、湧、夢、萬採其對應簡化字草形；釋文以繁體呈現。

## 筆觸系統

1. `extract-glyphs.py` 以 Pillow 將字體字形轉為遮罩。
2. 二階段細化提取字形的中心線圖，距離場估計筆畫局部半徑。
3. 圖遍歷與 Catmull–Rom 插值建立逐段揮寫路徑；此為演算法近似的書寫順序。
4. 種子改變字群伸縮、欹側、位置與牽絲，保持文字骨架。
5. 局部半徑、路徑速度與筆壓變化形成筆觸外緣。細絲用獨立的低壓路徑連接字群。
6. 含墨量與重新蘸墨的節奏改變實墨透明度；短而不規則的內部缺墨線形成飛白。
7. 紙纖維與朱印以程式繪製，種子可重現。
8. 完成的筆跡快取在透明畫布，動畫每幀只重繪正在形成的一筆。

主程式沒有外部依賴與遠端字型請求；開啟 `index.html` 即可離線欣賞。Pillow 僅用於開發期的字形提取，觀看作品不需要 Python。

## 操作

- **勢 · 收放**：在揮毫中漸變筆觸重量；後續字群採用新的欹側、伸展與連筆設定。
- **墨 · 枯潤**：逐漸改變尚未落筆部分的含墨量與飛白，已寫下的部分保留。
- **白 · 疏密**：重新安排尚未開始的字群，正在寫的字保持原位置；剩餘章法會自動縮合於紙面內。
- **速 · 疾徐**：即時調整揮毫速度，維持播放進度。
- **卷號 / 種子**：固定參數下，輸入相同卷號可重現墨卷。途中調參所形成的版本取決於調整時機。
- **換一卷**：以新種子產生新的章法與墨色變化。
- **從頭揮毫**：用相同種子及目前參數重新書寫整卷。
- **暫停 / 繼續**：停留或繼續書寫；空白鍵亦可操作。
- **觀筆**：拖動時間，檢視一筆形成的細節，並保留本次揮毫途中已記錄的參數變化。
- **藏此卷**：下載目前進度的 3200 × 2200 PNG。

一般情況預設會逐筆形成整卷；開啟系統減少動態效果設定時，直接顯示完成畫面。按「從頭揮毫」可主動觀看書寫。
